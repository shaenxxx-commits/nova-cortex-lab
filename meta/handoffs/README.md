# Handoffs

Archive of session handoffs. Append-only.

- `meta/handoff-current.md` — живой снимок текущего
  состояния. Обновляется при значимых этапах.
- Этот каталог — копии снимков с датой в имени:
  `YYYY-MM-DD-<тема>.md`.

Схема работы:
1. Значимое событие произошло.
2. Обновляется `meta/handoff-current.md`.
3. Копия кладётся сюда с датой и темой.
