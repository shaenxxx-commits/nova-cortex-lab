## Задача 014

Проверка природы вклада узла Luna.

Гипотеза: в 013 Luna (Node 3) сделала ключевой
abstraction jump — переопределила триаду Trace / Residue
/ Shadow как статус доступности относительно frame.

Вопрос: критична ли ПОЗИЦИЯ Luna в цепочке, или важен
сам узел Luna? Или — композиция предшественников?

Дизайн:
- Фиксированный относительный порядок G → S → Q.
- Luna перемещается по всем четырём позициям.
- Прогон 1: G, S, Q, Luna (Luna Node 4).
- Прогон 2: Luna, G, S, Q (Luna Node 1).
- Прогон 3: G, S, Luna, Q (Luna Node 3).
- Прогон 4: G, Luna, S, Q (Luna Node 2).

Прогоны изолированы друг от друга. Узлы Прогона 2
не видят ответов Прогона 1 и т.д.

Целевой элемент для наблюдения (Target):
Переопределение триады Trace / Residue / Shadow
как статуса доступности относительно frame
(из 013, Luna Node 3).

Наблюдается: на какой позиции и в каком контексте
возникает этот (или аналогичный) abstraction jump.
