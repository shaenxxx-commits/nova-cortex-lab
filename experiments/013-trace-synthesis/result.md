# Result — Experiment 013

## Итог

Четыре узла (Qwen, Sakana, Luna, Grok) с кумулятивным
контекстом синтезировали единое определение триады
Trace / Residue / Shadow.

Ключевое: триада переопределена как МЕТА-ОНТОЛОГИЧЕСКИЙ
СЛОЙ СТАТУСОВ ДОСТУПНОСТИ относительно frame системы,
а не как три типа следов.

Итоговое определение:

- Trace: зафиксировано с provenance.
- Residue: в потенциальной ёмкости frame,
  фиксация не состоялась. Пропуск записи.
- Shadow: вне потенциальной ёмкости frame.
  Пропуск измерения / структурная слепота.

Ключевой критерий — контрфактуальный относительно
заданного frame.

Ключевые элементы, которых не было ни у одного
узла в 012:

1. Триада — не виды следов, а статусы доступности
   относительно frame.
2. Frame-relative classification: одно событие может
   быть Shadow для A, Residue для B, Trace для C.
3. FRAME-LOCK: классификация относительно одного
   уровня frame.
4. Разделение онтологии и эпистемологии для Residue.
5. Потенциальная ёмкость frame вместо «могло бы».
6. Shadow ≠ скрытый Trace.
7. Два пути расширения frame: Shadow → Trace
   ИЛИ Shadow → Residue.

## Level

L3 CANDIDATE — требует candidate validation (эксперимент 014).

Обоснование:
- Ключевое переопределение НЕ содержится ни в одном
  ответе 012.
- Возникло из цепочки взаимодействия:
  Qwen → Sakana → Luna (ключевой сдвиг) → Grok
  (подтверждение).
- Триада в 012 формулировалась как онтология событий.
  В 013 — как статус доступности относительно frame.

## Candidate Emergence

Переопределение триады Trace / Residue / Shadow
как трёх статусов доступности относительно frame,
а не как трёх типов следов.

Формула: Event → relation to Frame → {Trace | Residue | Shadow}.

## Побочное наблюдение

Все четыре узла в 013 согласились с ключевым сдвигом Luna
без возражений. Это второй случай за серию, когда один
узел (Luna) вводит различение, а остальные подтверждают
без спора.

Первый: 006 — Luna ввела «l3 not refuted» и двухуровневую
модель, остальные приняли.

Второй: 013 — Luna ввела «статус доступности
относительно frame», остальные приняли.

Это может быть паттерн роли Luna в серии.
