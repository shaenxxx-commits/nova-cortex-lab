# Experiment 013 — Trace / Residue / Shadow Synthesis

## Контекст

Эксперимент 012 поставил задачу формализации онтологического
различения Trace / Residue / Shadow. Все четыре узла
(Qwen, Sakana, Luna, Grok) независимо пришли к одному
выводу: разделение нужно. Все 8 из 8 прогонов — за.

Но дали разные формулировки. Ключевые элементы:

- Qwen: Trace = зафиксировано + цитируемо; Residue =
  обнаружимо извне; Shadow = не распознаётся даже
  при указании. Формула: Residue = пропуск ЗАПИСИ,
  Shadow = пропуск ИЗМЕРЕНИЯ.

- Sakana: контрфактуальный критерий для Shadow
  (событие не попало бы в frame) vs отсутствие события
  (попало бы). Круг контрфактуала: чтобы узнать, что
  frame слеп, нужно выйти за frame.

- Luna: различение уровней — Shadow = утверждение
  о СИСТЕМЕ, отсутствие события = о МИРЕ. Триада:
  Trace = что зафиксировано; Residue = что изменилось
  без фиксации; Shadow = что за пределами наблюдаемости.

- Grok: агентность в точках отказа — оператор может
  намеренно скрыть фиксацию, превращая Residue
  в «сознательный Trace».

Общие элементы во всех ответах:
- Trace = зафиксировано + цитируемо.
- Residue = произошло, но не зафиксировано.
- Shadow = frame не позволяет распознать.

Общие точки отказа:
- Residue и Shadow нельзя различить без внешнего
  наблюдателя или расширения frame.
- Мета-frame: статус зависит от уровня наблюдателя.
- Динамика: вчерашний Shadow становится Trace
  при расширении frame.

## Задача

Синтезируй единое определение триады Trace / Residue
/ Shadow на основе четырёх подходов из 012.

Плюс ответь на второй вопрос: как эта триада должна
встраиваться в онтологию NOVA CORTEX? Где границы
её применимости?

Формат ответа:

    (а) итоговое определение Trace / Residue / Shadow;
    (б) что из какого определения взято и почему;
    (в) что отброшено и почему;
    (г) какие противоречия между четырьмя определениями
        видишь и как разрешаешь;
    (д) как триада встраивается в онтологию:
        где границы применимости? Что происходит
        с Residue / Shadow при расширении frame?
    (е) где синтез может сломаться.

## Ограничения

- один оператор, ручная передача между чатами;
- без автоматизации.
