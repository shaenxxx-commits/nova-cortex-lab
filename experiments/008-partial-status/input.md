# Experiment 008 — Partial Status

## Контекст

В METHOD v2 (раздел 5.2) шкала воспроизведения имеет
три состояния: YES / NO / AMBIGUOUS.

В эксперименте 007 (baseline-проверка L3-кандидата из 006)
один прогон (Luna Run 2) дал результат, который сейчас
попадает в AMBIGUOUS, но качественно отличается от
типичного AMBIGUOUS:

- Luna Run 2 дала ДРУГОЕ разделение (шкала vs тест+условия),
  не Target (семантика vs процедура).
- То есть она не воспроизвела Target, но пришла к родственной
  идее разделения.

Сейчас это классифицируется как AMBIGUOUS. Но AMBIGUOUS
смешивает два разных случая:
- результат неопределён (данных недостаточно, противоречия);
- результат содержит ЧАСТИЧНОЕ приближение к Target.

Это разные вещи. Первое — отсутствие информации. Второе —
наличие информации, но не той.

## Задача

Предложи формальное определение статуса PARTIAL —
частичного приближения — для шкалы воспроизведения.

Или обоснуй, почему PARTIAL не нужен и AMBIGUOUS
достаточно.

Формат ответа:

    (а) нужно ли отдельное состояние PARTIAL?
        Если да — его определение.
        Если нет — обоснование, почему трёх достаточно.
    (б) как отличить PARTIAL от YES, NO и AMBIGUOUS;
    (в) пример на конкретном случае (можно использовать
        случай Luna Run 2 из 007);
    (д) где определение может сломаться.

## Ограничения

- один оператор, ручная передача между чатами;
- без автоматизации;
- определение должно быть коротким — применимым
  без долгих раздумий.
