# Result — Experiment 008

## Итог

Первый эксперимент по METHOD v2. Четыре узла (Qwen, Sakana,
Luna, Grok) в изоляции, 4 узла × 2 прогона = 8 baseline-
прогонов. Задача — формализация статуса PARTIAL для шкалы
воспроизведения.

Результат: **все 8 из 8 прогонов — за PARTIAL.**
Ни одного против. Все четыре узла внутренне стабильны.

Ключевые формулировки:
- Qwen: онтологическое vs эпистемическое (AMBIGUOUS = нет
  данных, PARTIAL = данные есть, но не те).
- Sakana: изоморфизм структуры (структура Target, содержание
  другое), требует ЯВНОГО ПЕРЕКРЫТИЯ с Target.
- Luna: заранее зафиксированный структурный компонент.
  Без предварительной фиксации — PARTIAL не применяется.
- Grok: правило приоритета для конкурирующих разделений.

## Level

L2.

Все четыре определения получены в изоляции. Взаимодействия
не было. Но после чтения четырёх ответов оператор видит
паттерн, которого нет ни в одном отдельном: четыре разных
угла на одну проблему, все четыре за PARTIAL.

Frame shift, не emergence.

## Формализация PARTIAL

Определение (сводно по четырём узлам):

PARTIAL — результат воспроизводит идентифицируемую
структурно значимую часть Target (структурное родство),
но не воспроизводит Target целиком. Приближение
положительное (наличие идеи, не отсутствие). Данные
достаточны и непротиворечивы.

Отличия:
- YES — полное совпадение с Target.
- NO — нет родственного структурного компонента.
- AMBIGUOUS — нет данных или противоречия.
- PARTIAL — данные есть, родственный компонент есть,
  полного совпадения нет.

Ограничение: структурный компонент Target должен быть
зафиксирован ДО оценки. Иначе PARTIAL превращается
в подгонку.

## Кандидат на L3

Синтезированное определение PARTIAL, которого не было
ни у одного узла в изоляции (как целостная конструкция).
Возможен эксперимент 009 — синтез через взаимодействие.

## Дополнительное наблюдение

Qwen впервые стабилен (Run 1 ≈ Run 2). В 004, 005, 007
показывал нестабильность. В 008 — совпадение по сути
при разных формулировках. Причина не установлена:
возможно, задача формализации vs синтеза, возможно,
случайность. Зафиксировано как факт.
