## Задача 011

Повторная candidate validation L3-кандидата из 009
БЕЗ узла-автора (Luna).

Цель: различить WITHIN-NODE и INTERACTION-ONLY
по правилу раздела 5.3 METHOD v4.

Обоснование исключения Luna:
В 010 Luna Run 2 дала YES на Target из 009. Luna —
автор различения (ввела его в 009). Это WITHIN-NODE,
не INDEPENDENT. Для различения WITHIN-NODE
и INTERACTION-ONLY нужен прогон без автора.

## Target

Различение «уровень прогона vs уровень агрегации
серии как две отдельные задачи».

Формулировка: PARTIAL у отдельного прогона — это
классификация прогона. Итоговый вердикт серии —
отдельное решение об агрегации, которое нельзя
автоматически вывести из определения PARTIAL.
