L3 требует «паттерн невозможно получить в изоляции
у любого из узлов».
Luna Run 2 показала: возможно. Различение доступно
в изоляции, если узел, вводящий его, получает
тот же input.

Оговорка:
Luna Run 2 — не независимое воспроизведение.
Это воспроизведение собственной работы в 009.
Технически — да, L3 опровергнут. Но случай
не идентичен независимому воспроизведению
другим узлом.

Для строгого подтверждения L3 нужно было бы,
чтобы ни один узел, включая автора различения,
не воспроизвёл его в изоляции. Этого не произошло.

Новый статус 009: L2 с частичным вкладом
взаимодействия.

## Operator Notes

010 дал три результата:

1. L3-кандидат из 009 понижен до L2.
   Формально: YES у Luna Run 2 опровергает кандидата.
   Содержательно: опровергнут одним узлом — автором
   различения. Это отдельный случай.

2. Впервые в серии шкала 5.2 METHOD v2 (с PARTIAL)
   применена в реальной оценке. Результат:
   - 1 YES,
   - 5 PARTIAL,
   - 2 NO,
   - 0 AMBIGUOUS.
   PARTIAL дал градацию между «нет» и «да»,
   которой не было бы по трёхзначной шкале.

3. Luna Run 1 ≠ Run 2. В Run 1 — PARTIAL,
   в Run 2 — YES. Внутренне нестабильна в 010,
   хотя в 008 и 009 была стабильна.

Ключевой вопрос для 011 или отдельного решения:
как трактовать случай, когда L3-кандидат опровергается
тем же узлом, который его ввёл? Это «опровержение»
в строгом смысле, или это особенность одного узла,
требующая дополнительной проверки другими узлами?

Формально по METHOD v2 — опровержение.
Содержательно — опровержение только одним узлом.
Разница существенная.

Наблюдение о роли Luna: в 009 она ввела различение,
в 010 подтвердила его в изоляции. Это устойчивый
паттерн reasoning-модели — способность воспроизводить
собственную работу.

Дополнительно: Sakana × 2 и Grok × 2 дали PARTIAL —
содержат родственный компонент, но не полное различение.
Это говорит, что различение «уровень прогона vs уровень
агрегации» доступно разным узлам в разной степени.
Не полностью, но частично.
