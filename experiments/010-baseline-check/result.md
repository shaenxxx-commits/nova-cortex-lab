# Result — Experiment 010

## Итог

Baseline-проверка L3-кандидата из 009. Восемь прогонов
(4 узла × 2) на input.md из 009 в изоляции.

Результат:
- 1 YES (Luna Run 2)
- 5 PARTIAL (Sakana × 2, Luna Run 1, Grok × 2)
- 2 NO (Qwen × 2)
- 0 AMBIGUOUS

Формально: L3-кандидат из 009 ОПРОВЕРГНУТ (YES у Luna Run 2).

Содержательно: опровергнут одним узлом — Luna, которая
сама ввела это различение в 009. Это воспроизведение
собственной работы, не независимое открытие.

## L3 Check

Вердикт по правилу из 007:
- YES хотя бы у одного → L3-кандидат ОПРОВЕРГНУТ.
- Все NO → кандидат подтверждён.
- AMBIGUOUS без YES → контроль не дал однозначного
  результата.

Фактически: 1 YES → формальное опровержение.

Оговорка: YES дала Luna Run 2 — узел, вводивший
различение в 009. Это не независимое воспроизведение
другим узлом.

## Level Assignment

L3 CANDIDATE из 009:
- **ПОНИЖЕН ДО L2.**

Обоснование по METHOD v2 раздел 7:
L3 требует «паттерн невозможно получить в изоляции
у любого из узлов». Luna Run 2 показала: возможно.

Новый статус 009: L2 с частичным вкладом взаимодействия.

## Побочное наблюдение

Первое применение шкалы 5.2 METHOD v2 (с PARTIAL)
в реальной оценке. Результат:
- 1 YES,
- 5 PARTIAL,
- 2 NO,
- 0 AMBIGUOUS.

PARTIAL дал градацию между «нет» и «да»,
которой не было бы по трёхзначной шкале.

Sakana × 2 и Grok × 2 дали PARTIAL — содержат
родственный компонент («вердикт прогона»),
но не полное различение уровней.

## Открытый вопрос

Как трактовать случай, когда L3-кандидат опровергается
тем же узлом, который его ввёл?

Формально по METHOD v2 — опровержение.
Содержательно — опровержение только одним узлом.
Разница существенная.

Возможно, нужно правило: если YES даёт автор
различения, требуется дополнительная проверка
другими узлами до финального вердикта.
