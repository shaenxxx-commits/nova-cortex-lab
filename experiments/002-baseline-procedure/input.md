# Experiment 002 — Baseline Procedure

## Задача

В METHOD.md есть критерий L3: результат не считается
emergence, если его можно получить, скормив исходный
input любому из участвовавших узлов в изоляции.

Но процедуры проверки этого критерия в протоколе нет.
Оператор должен решить, «воспроизводится ли результат
в изоляции», опираясь на интуицию.

Предложи процедуру контрольного изолированного прогона
(baseline), которая закрыла бы этот критерий.

Формат ответа:

    (а) пошаговая процедура;
    (б) что фиксируется в trace.md — какие поля, блоки,
        структура;
    (в) где процедура может сломаться и как это заметить.

## Ограничения

- один оператор, ручная передача между чатами;
- 3–5 узлов;
- без автоматизации;
- процедура должна быть выполнима в этих условиях.

## Условия

- Другие файлы репозитория читать не обязательно.
- Ответ будет зафиксирован без редактуры.
- Язык — русский.

## Ограничение

Задача не меняется после старта эксперимента.
Любые правки — через новый эксперимент или через trace.md.
