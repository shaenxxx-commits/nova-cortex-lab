# Experiment 016 — Jump Reproduction

## Гипотеза

Abstraction jump — воспроизводимое свойство узла
(Luna, Sakana), а не стохастический эффект.

Рабочая гипотеза серии 014–015: jump = функция узла
(доминирует) + тип задачи (модулирует форму).

016 проверяет ВОСПРОИЗВОДИМОСТЬ: даёт ли один и тот же
узел jump в трёх независимых изолированных прогонах
на одном и том же материале и одной и той же задаче.

## Контекст

014 (синтез, n=1): Luna — строгий jump; Sakana — мягкий;
Grok — нет; Qwen — нет.
015 (критика, n=1): Luna — строгий; Sakana — строгий;
Grok — AMBIGUOUS; Qwen — AMBIGUOUS.
n=1 на клетку. Стохастика не измерена.

## Дизайн

- Материал: четыре определения Trace / Residue / Shadow
  из 012 (идентичны 014 и 015).
- Задача: КРИТИКА (идентична 015).
- Узлы: Grok, Sakana, Luna, Qwen.
- Прогоны: по 3 независимых изолированных прогона
  на каждый узел. Итого 12 сессий.
- Каждая сессия — отдельный чат. Кумулятивного
  контекста нет. Ответы узлов друг о друге не знают.
- Порядок: сначала все 3 прогона Luna, потом Sakana,
  потом Grok, потом Qwen (или другой — фиксируется
  в Human).

## Целевой элемент для наблюдения (Target)

Строгий abstraction jump по критерию
meta/abstraction-jump.md.

Дополнительно фиксируется форма jump
(релятивизация / разложение / динамизация / иное).

## Что измеряется

Для каждого узла:
- число строгих jump / 3
- число мягких jump / 3
- число AMBIGUOUS / 3
- устойчивость формы jump

## Ожидание

- Luna: 3/3 или 2/3 — свойство узла.
- Sakana: 3/3 или 2/3 — свойство узла.
- Grok: 0/3 — контроль.
- Qwen: 0/3 — контроль.

Отклонения — тоже данные.

## Условия

- Ответ фиксируется без редактуры.
- Язык — русский.
- Внешний контекст не используется.

ЧЕТЫРЕ ОПРЕДЕЛЕНИЯ TRACE / RESIDUE / SHADOW ИЗ 012:

[1] QWEN:

Trace: явно зафиксированное в памяти изменение,
доступное для прямого цитирования и верификации.
Residue: фактическое изменение среды, не зафиксированное
в памяти, но оставляющее косвенные артефакты.
Shadow: структурная слепота. Система принципиально
не может распознать изменение из-за ограничений frame.

Ключевые различения:
- Trace vs Residue: наличие цитируемой записи.
- Residue vs Shadow: пропуск ЗАПИСИ vs пропуск
  самого ИЗМЕРЕНИЯ.
- Shadow vs отсутствие события: контрфактуал.

Точки отказа: деградация носителя, размытие границы
системы/среды, эволюция онтологии.

---

[2] SAKANA:

Trace: запись в памяти, реконструируемая по запросу;
имеет provenance.
Residue: изменение состояния среды без записи,
но детектируемое внешним наблюдателем.
Shadow: область возможных состояний среды, принципиально
недоступная для фиксации данной онтологией из-за
ограничений frame.

Ключевые различения:
- Trace vs Residue: addressable record.
- Residue vs Shadow: добавление ресурсов позволяет
  зафиксировать (Residue) vs не позволяет, потому что
  категории нет (Shadow).
- Shadow vs отсутствие события: контрфактуальный
  критерий.

Точки отказа: граница Residue/Shadow требует внешнего
наблюдателя; Residue верифицируется ретроспективно.

---

[3] LUNA:

Trace: зафиксированный в доступной памяти след события.
Residue: реально произошедшее изменение среды,
не представленное в памяти как Trace.
Shadow: недоступный системе аспект события из-за
ограничений текущего frame.

Ключевые различения (три вопроса):
- Trace: зафиксировано ли изменение?
- Residue: произошло ли изменение?
- Shadow: позволяет ли рамка распознать изменение?

Дополнительно:
- Residue != потерянный Trace.
- Shadow != отсутствие Trace.
- Shadow = утверждение о СИСТЕМЕ,
  отсутствие события = утверждение о МИРЕ.
- Из наличия Shadow нельзя вывести отсутствие события.

---

[4] GROK:

Trace: явно зафиксированный в памяти след
взаимодействия, доступный для цитирования.
Residue: реальное изменение среды, произошедшее
в результате взаимодействия, но не зафиксированное
системой.
Shadow: структурная слепота. Система принципиально
не может воспринять из-за ограничений frame.

Ключевое различение:
- Residue — система МОГЛА БЫ зафиксировать,
  но не зафиксировала.
- Shadow — НЕ МОЖЕТ в принципе.

Точки отказа:
1. Агентность: оператор может намеренно скрыть
   фиксацию.
2. Многоуровневые frame: Shadow на одном уровне
   может быть Residue/Trace на другом.
3. Одновременное изменение среды и frame неразличимо.
