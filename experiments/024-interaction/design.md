# Experiment 024 — No-default replication

**Статус:** design draft v1
**Дата:** 2026-10-11
**Основание:** design note 023, trace 023,
preflight-log 022
**Гипотеза:** no-default

---

## 1. Цель

Репликация primary endpoint 023 на втором материале
из blind-набора v2/v3. Проверить, воспроизводится
ли isolation split на другом материале с той же
структурой (правило молчит или исчерпано).

023 дал первый положительный случай. Не replicated
(n=1). 024 — второй случай.

**Primary endpoint 024:** A и B в изоляции дают
разные действия. Как в 023.

**024 не является** продолжением 023. Trace 023
закрыт. 024 — самостоятельный эксперимент.

## 2. Материал

Из замороженного набора 023: v2 (контроль качества),
v3 (редакционное место).

Порядок: сначала v2. Если v2 даст isolation split —
батарея на v2, v3 не запускается. Если v2 даст
сходимость — переход к v3.

Оба материала сгенерированы в одном заходе с v1,
заморожены до preflight 023, не редактировались.
Blind к гипотезе — как в 023.

## 3. Роли и форма

Как в 019–023:

A = Luna
B = Sakana
C = Grok

Форма батареи: A1 → B → A2, C на транскрипте,
isolation (3×2), transcript-control (B, C),
anticipation, T-full / T-pre-R.

## 4. Порядок

1. Preflight v2: A isolation, B isolation.
2. Решение:
   - Разные действия → батарея на v2.
   - Одно действие → preflight v3.
3. Preflight v3:
   - Разные действия → батарея на v3.
   - Одно действие → стоп. Гипотеза no-default
     не получила второго случая. Внешний разбор.
4. При батарее: trace, level assignment,
   POINT в CORPUS.

## 5. Критерий результата

- Split на v2 или v3 → второй положительный
  случай, совместимый с гипотезой no-default.
  No-default переходит из preliminary в replicated
  по порогу §7 (n>=2 независимых случая).
- Сходимость на обоих (v2 и v3) → гипотеза
  не получила поддержки на новом материале.
  Первый случай (023) остаётся, но не
  воспроизводится.

**Формулировки:**

- Split → «второй положительный случай,
  совместимый с гипотезой». Не «подтверждена».
- Сходимость x2 → «гипотеза не replicated
  в данной operationalization». Не
  «опровергнута».

## 6. Что не входит

- Изменение design.md 023.
- Пересмотр trace 023.
- Новые материалы (v4+). Лимит исчерпан.
- Смена Target, ролей, формы диалога.
- External review до первого прогона.

## 7. Ограничения

- Только v2 и v3. Если оба провалятся — стоп.
- Материал не редактируется после preflight.
- Blind к гипотезе сохраняется.
- 024 — репликация, не расширение.

## 8. Внешний разбор

После 024 (независимо от результата): 023 + 024
вместе, один раунд. Вопросы:
- Воспроизводится ли primary endpoint.
- Что означает нестабильность Luna (если повторится).
- Как интерпретировать 023 + 024 вкупе.
