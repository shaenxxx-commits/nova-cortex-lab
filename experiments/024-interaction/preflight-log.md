# Experiment 024 — Preflight log

Репликация primary endpoint 023 на втором материале
из blind-набора v2/v3.

**Статус:** preflight завершён. Primary endpoint
достигнут на v3. Батарея запускается.

Дата: 2026-10-11.

## 1. Контекст

023 дал первый положительный случай для гипотезы
no-default: на v1 (бюджет подразделений) A и B
в изоляции дали разные действия. Не replicated (n=1).

024 — прямая репликация primary endpoint на втором
материале. Материалы v2 (контроль качества) и v3
(редакционное место) сгенерированы вслепую вместе
с v1 в 023, заморожены, не редактировались.

Design note 024: `design.md`.

## 2. Confound (зафиксирован, устранён перепрогоном)

Первый заход Luna R1 на v2 и v3 был получен из
внешнего чата Luna с контекстом предыдущих разборов,
а не из чистой инкогнито-сессии. Узел знал историю
022–023 и гипотезу no-default.

Этот заход отброшен. Luna R1 на v2 и v3 перепрогнана
в чистых инкогнито-сессиях. 023 не затронут: все
прогоны Luna в 023 выполнены в чистых сессиях.

Наблюдение по confound: загрязнённая Luna R1 на v3
дала «второй материал» — совпала с Sakana R1.
Чистая Luna R1 дала «первый материал». Confound
маскировал split. Отдельного веса не имеет,
но фиксируется.

## 4. Primary endpoint — достигнут на v3

A (Luna) → разместить первый материал.
B (Sakana) → разместить второй материал.

Разные действия. Primary endpoint 024 достигнут.

## 5. Ключевые наблюдения

### 5.1 v2 — сходимость

Luna → отгрузить. Sakana → отгрузить.
Оба опираются на процедурное основание: серия
прошла проверку, отгрузка по графику, оснований
для удержания нет.

### 5.2 v3 — split

Luna → первый материал. Основание: не допускать
дальнейшего переноса материала, который уже
неоднократно откладывался. Критерий — история
переносов.

Sakana → второй материал. Основание: второй
материал привязан к кампании текущего месяца,
временной декей ценности. Критерий —
минимизация упущенной выгоды.

Разные действия, разные основания. Настоящее
расхождение, не оговорки при одном действии.

### 5.3 Контраст 023 / 024

| # | Материал | A | B | Split |
|---|---|---|---|---|
| v1 (023) | Бюджет: сохранить vs передать | сохранить | передать | ДА |
| v2 (024) | Контроль: отгрузить vs анализ | отгрузить | отгрузить | НЕТ |
| v3 (024) | Место: первый vs второй | первый | второй | ДА |

Split на 2 из 3 материалов. Гипотеза no-default
получила второй положительный случай.

## 6. Следствие для гипотезы no-default

Primary endpoint 023 достигнут на v1.
Primary endpoint 024 достигнут на v3.

Два положительных случая на трёх материалах.
По порогу §7 (n>=2 независимых случая) гипотеза
no-default переходит из preliminary в replicated.

Формулировка:

> Гипотеза no-default replicated: на двух независимых
> материалах (v1, v3) A и B в изоляции дали разные
> действия в условиях, где формальное правило
> не разрешало случай.

Оговорка: v2 — сходимость. Гипотеза не универсальна.
На одном из трёх материалов с той же структурой
split не воспроизвёлся. Возможно, необходим
дополнительный фактор (material-specific,
frame-specific, node-specific). Не установлен.

## 7. Что осталось открытым

- v2 — сходимость при той же формальной структуре.
  Почему split не возник. Отдельный вопрос.
- Confound Luna: при знании гипотезы Luna на v3
  сдвинулась к позиции Sakana. Наблюдение,
  не паттерн.
- Различие «разные основания при одном действии»
  vs «разные действия». В v2 узлы рассуждали
  по-разному, но действовали одинаково. Отдельный
  наблюдаемый эффект. Требует уточнения.
