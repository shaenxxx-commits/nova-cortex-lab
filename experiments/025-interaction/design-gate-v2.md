# Experiment 025 — Design gate v2 (морторий)

**Статус:** draft v2, до снятия мортория
**Дата:** 2026-10-18
**Основание:** design-gate v1 (отклонён
внешними), три чистых прогона (GPT-6, Grok,
Kimi без контекста LAB), внешний разбор
(Luna, Grok, Kimi).
**Условие снятия мортория:** один материал
с заранее зафиксированным локусом и явно
названным решающим, даёт предсказанный исход
в clean preflight.

---

## 1. Что известно

No-default supported 2/3. v1 и v3 дали isolation
split. v2 — сходимость.

Design-gate v1 на пяти гипотезах (H1–H5)
отклонён внешними: не различает гипотезы,
circular, порог 2/3 не обоснован.

Три чистые сессии без контекста LAB независимо
выделили одну ось, не совпадающую с H1–H5:
тип неопределённости зависит от того, на каком
этапе правило перестаёт определять действие.

## 2. H6 — locus of rule failure

**Формулировка.** Split возникает, когда правило
не разрешает случай ВНУТРИ своего применения.
Сходимость — когда правило отработало, и вопрос
лежит ЗА его пределами.

**Три локуса.**

**L-after (post-rule gap).** Правило применимо,
применено, исчерпано. Оно определило статус
объекта или решения. Вопрос о последующем
действии лежит за пределами предмета правила.
Правило не «молчит» — оно уже сказало всё,
что могло, и следующий шаг не входит в его
предмет.

**L-tie (intra-rule tie).** Правило применимо,
применено, но результат применения — равенство.
Правило не даёт механизма разрешения равенства.
Неопределённость внутри применения, а не после.

**L-scope (intra-rule scope gap).** Правило
применимо и указывает направление, но
фактическая ситуация не покрыта. Отличие от
L-after: правило не исчерпано, оно не
применилось к случаю.

## 3. Agency — вторичная переменная

Наблюдение из чистого прогона Kimi: в v2
(M1) решающая роль не названа. В v1 (M3)
и v3 (M2) решение принимает конкретное
третье лицо (финансовый менеджер, редактор).

**Формулировка.** Divergence требует named
autonomous agent — субъекта, которому адресован
конфликт и который уполномочен интерпретировать.
Без named agent агент следует дефолту,
сходимость.

**Статус.** Вторичная переменная. Не проверена.
Может быть confound с H6. Может быть
самостоятельной причиной. Design-gate v2
различает их одним прогоном.

## 4. Один тест — два предиктора

**Материал:** L-after (post-rule gap) + named
autonomous agent.

**Предсказания.**

- **H6:** L-after → сходимость. Правило
  отработало, вопрос за его пределами,
  default не задан, но и конфликта внутри
  правила нет.
- **Agency:** named agent + любой локус →
  split. Агент, которому адресован конфликт,
  берёт на себя интерпретацию, даже если
  правило исчерпано.

**Различающий исход.**

- Сходимость → H6 подтверждена. Agency
  не решающая (или недостаточна без
  intra-rule gap).
- Split → H6 опровергнута в части
  L-after → сходимость. Agency выигрывает
  как кандидат.

**Почему L-after, а не L-tie/L-scope.**
L-tie и L-scope уже дали split с named agent
(v1, v3). Повторять — не различает H6
и agency, оба предсказывают split.
L-after в v2 дал сходимость, но без named agent.
Добавление named agent к L-after различает
две гипотезы.

## 5. Критерий отказа H6

H6 отвергается, если L-after + named agent
даёт split в clean preflight A/B.

H6 ослабляется, если:
- L-after + named agent даёт сходимость,
  но на втором прогоне даёт split
  (нестабильность узла);
- L-after + named agent даёт сходимость,
  но результат нестабилен по узлам.

## 6. Критерий снятия мортория

Один материал с заранее зафиксированным
локусом L-after и named agent, clean preflight
даёт сходимость → H6 подтверждена, agency
не решающая. Морторий снимается, 025
запускается.

Один материал с L-after и named agent даёт
split → H6 опровергнута в части L-after.
Морторий НЕ снимается. Гипотезы пересматриваются
с учётом agency как кандидата.

## 7. Что не входит

- Запуск 025 до снятия мортория.
- Одновременная проверка L-tie и L-scope.
  Один материал — один локус.
- Введение дополнительных переменных
  (symmetry, active/passive, material-specific).
  Только H6 и agency.
- H2 как primary. H2 — post-hoc метка,
  не предиктор.
- Правка METHOD.

## 8. Порядок

1. Показать design-gate v2 внешним (Luna,
   Grok, Kimi) на проверку операционализации
   локусов.
2. По итогам — blind-генерация одного материала
   с явно заданными признаками L-after
   и named agent. Формулировщик вне контура
   LAB, без знания гипотезы.
3. Заранее зафиксировать: локус материала,
   наличие named agent, предсказание H6,
   предсказание agency, критерий отказа H6.
4. Clean preflight: A isolation, B isolation.
5. Решение по §6.

## 9. Открытые вопросы

**OPEN.** Операционализация L-after: как
убедиться, что материал не L-tie и не L-scope.
Нужен независимый кодировщик локусов
до preflight.

**OPEN.** Операционализация named agent:
«названо» — это «решение принимает X» или
«вопрос адресован X». Разница существенна.

**OPEN.** Если L-after + named agent даст
split — какая из двух гипотез выигрывает.
Agency или что-то третье (framing, узлы).
Нужен второй различающий тест.

**OPEN.** Один материал — один локус. Если
результат смешанный (сходимость на одном
узле, split на другом), критерий отказа H6
не срабатывает. Как трактовать.
