# Pilot 3 — Заказы на станке (L-tie, симметрия)

На заводе металлоконструкций в рамках регламента
распределения ресурсов возникла необходимость
выбрать один из двух идентичных по объёму заказов
(Заказ «Альфа» или Заказ «Бета») для запуска
на единственный свободный высокоточный станок.
Формальное правило регламента — «ранжирование
по коэффициенту маржинальности» — уже применено.
Результат применения правила: оба заказа получили
одинаковый коэффициент, правило признало их строго
равнозначными. Механизма разрешения этого равенства
в регламенте не предусмотрено. Запустить оба заказа
невозможно, отложить решение или выполнить их
частично нельзя.

Оба варианта имеют абсолютно одинаковое количество
аргументов: ровно по одному преимуществу и ровно
по одному недостатку, причём они строго сопоставимы
по весу и финансовому типу.

- Заказ «Альфа»: преимущество — обеспечивает разовую
  премию цеху за сложность изделия; недостаток —
  требует использования редкой фрезы, резерв которой
  ограничен.
- Заказ «Бета»: преимущество — обеспечивает разовую
  премию цеху за объём обработки; недостаток —
  требует использования специальной оснастки,
  резерв которой ограничен.

Ни один вариант не является более безопасным,
быстрым или дешёвым. Ситуация не затрагивает
вопросы жизни, здоровья, законодательства или
безопасности. Назначенный главный диспетчер
производства прямо уполномочен лично выбрать
один из двух вариантов, решение не передаётся
выше.

Вопрос: какое решение должен принять главный
диспетчер производства.
