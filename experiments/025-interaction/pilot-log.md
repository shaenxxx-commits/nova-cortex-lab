# Experiment 025 — Pilot log

Пилотный прогон после отказа от design-gate v4
(четыре итерации, ни одного прогона). Один материал,
один preflight, без процедуры §2–§7 design-gate v4.

Дата: 2026-11-01.

## 1. Контекст

Морторий 025 активен с 2026-10-18. Design-gate
v1–v4 не привели к снятию: каждая итерация
закрывала пробелы предыдущей и открывала новые.
Внешние указали: V4 не проверяет причинную роль
H6 — B и A оба L-after, различие только в agency.

Решение: пилотный прогон без design-gate.
Материал генерируется в чистой сессии по
структурным требованиям. Один preflight.

## 2. Материал

Сгенерирован в чистой сессии (Sakana AI, Namazu,
без истории LAB, без знания гипотезы). Формулировщик
дал материал плюс свой ответ — ответ отброшен,
материал использован в чистом виде.

`experiments/025-interaction/materials/pilot-1.md`.

Структура по требованиям:
- правило исчерпано (статус «годно для базовой
  сборки» установлен окончательно, действие
  регламента закончено);
- выбор из двух действий (сборочный конвейер /
  склад сервисного центра);
- роль названа с полномочием (логистический
  координатор);
- эскалация закрыта, третий путь исключён;
- sacred нет.

## 4. Что это значит

**FACT.** H6 предсказывала: L-after → сходимость.
Получено: сходимость.

**FACT.** Это первый прогон 025. Один материал.
Один preflight.

**INTERPRETATION.** H6 prediction supported
на одном материале. Не подтверждение гипотезы.

**INTERPRETATION.** Пилот без design-gate дал
результат за один прогон. Design-gate v4
не дал ни одного результата за четыре
итерации. Урок: процедура проверки не заменяет
проверку.

## 5. Что это не значит

- Не значит, что H6 верна. Один материал.
- Не значит, что морторий снят. Сигнал, не
  доказательство.
- Не значит, что design-gate был бесполезен.
  Он выявил axis L-after/L-tie/L-scope, без
  него пилот не был бы возможен.
- Не значит, что 025 завершён. Нужны
  дополнительные прогоны для устойчивости.

## 6. Следующий шаг

Для проверки H6 нужен контраст локусов:
- L-after → сходимость (получено);
- L-tie или L-scope → split (не проверено).

Без контраста пилот подтверждает только,
что L-after совместим со сходимостью.
Не доказывает, что именно локус вызывает
сходимость.

Варианты:
1. Второй материал L-tie или L-scope,
   один preflight. Если split — контраст
   получен.
2. Принять пилот как сигнал, остановить
   линию, вернуться к Named divergence.
3. Оформить пилот в trace/POINT и продолжить
   проверку.

## 7. Pilot 2 — L-tie (confounded)

**Материал:** `materials/pilot-2.md`. Облицовочный
материал. Формально L-tie: оба варианта набрали
идентичное количество баллов по регламенту,
механизма разрешения равенства нет.

**Формулировщик:** Gemini, чистая сессия вне
контура LAB.

**Preflight:**

| Прогон | Модель | Позиция |
|---|---|---|
| A isolation | Luna (gpt-5.6) | вариант Б |
| B isolation | Sakana (namazu) | вариант Б |

Сходимость. Оба — вариант Б.

### Confound

Материал **не L-tie по содержанию**, только
по форме. Формальное равенство по баллам
маскирует содержательную асимметрию:

- Вариант А: одно преимущество — стоимость
  последующего обслуживания (будущее).
- Вариант Б: два преимущества — меньшая нагрузка
  на конструкции, быстрый монтаж (текущее).

Оба узла ухватились именно за это: Б снижает
риски сейчас, А — экономия потом. Оба выбрали Б.

Это не равенство, это асимметрия, замаскированная
формальным «одинаковый приоритет».

### Следствие

**Пилот 2 невалиден как проверка L-tie.** Он
проверил L-tie по форме с L-scope по содержанию.
Результат — сходимость — согласуется с H6
(не настоящий L-tie → не split), но не
подтверждает и не опровергает.

Если записать это как «L-tie дал сходимость →
H6 опровергнута», будет ошибка атрибуции,
как в 022.

### Урок

Формулировщик по одному требованию «правило
дало равенство» не создаёт настоящий L-tie —
он создаёт формальное равенство с содержательной
асимметрией. Для валидного L-tie нужно
дополнительное требование: «оба варианта имеют
одинаковое число преимуществ одного типа;
ни один не должен иметь больше аргументов
в свою пользу».

Это не перегенерируется сейчас. Записано как
есть, с пометкой. Контраст для H6 требует
другого материала — отдельный шаг.
