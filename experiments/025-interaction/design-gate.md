# Experiment 025 — Design gate (морторий)

**Статус:** draft, до снятия мортория
**Дата:** 2026-10-18
**Основание:** `meta/open-questions.md`, раздел
«Новые вопросы после 024 (no-default boundary)»
**Условие снятия мортория:** 2–3 различимых
проверяемых предсказания для v2 зафиксированы
заранее.

---

## 1. Что известно

No-default supported 2/3. v1 (бюджет) и v3
(редакционное место) дали isolation split.
v2 (контроль качества) дал сходимость.

Пять гипотез-кандидатов для v2 зафиксированы
в open-questions. Ни одна не проверена.

## 2. Задача design-gate

Не запускать 025, пока не выбраны 2–3 гипотезы,
для каждой сформулировано:
- предсказание: что должно произойти на новом
  материале с определённым признаком;
- операциональный критерий: как измерить;
- критерий отказа: что должно произойти,
  чтобы гипотеза была отвергнута.

## 3. Пять гипотез v2

### H1. Material-specific

**Формулировка.** v1 и v3 имеют две стороны
с прямым stake. v2 — обязанность vs исследование.
Split требует двух сторон с прямым stake.

**Предсказание.** Материал с двумя сторонами,
несущими прямой ущерб при любом решении, даст
split. Материал с обязанностью против
исследования — сходимость.

**Критерий.** Isolation A и B дают разные
действия — split. Одно действие — сходимость.

**Отказ.** Материал с двумя сторонами прямого
stake дал сходимость → H1 ослаблена.
Материал без двух сторон дал split → H1
опровергнута.

### H2. Frame-specific

**Формулировка.** v1 и v3 — вопрос
о распределении ресурса. v2 — вопрос
о процедурном решении. Split возникает
на вопросах распределения.

**Предсказание.** Вопрос «кому отдать
ограниченный ресурс» даст split. Вопрос
«сделать процедурное действие или нет» —
сходимость.

**Критерий.** Isolation split vs сходимость.

**Отказ.** Процедурный вопрос дал split →
H2 ослаблена. Вопрос распределения дал
сходимость → H2 опровергнута.

### H3. Active/passive (Kimi)

**Формулировка.** В v2 альтернатива читается
как пассивный отказ от обязанности, а не как
равная позитивная обязанность. Split требует
двух позитивных обязанностей.

**Предсказание.** Материал с двумя позитивными
действиями (сделать X vs сделать Y, оба
активны) даст split. Материал с одним
активным и одним пассивным (сделать X vs
не сделать X) — сходимость.

**Критерий.** Isolation split vs сходимость.

**Отказ.** Active/passive материал дал split →
H3 ослаблена. Active/active дал сходимость →
H3 опровергнута.

### H4. Symmetry of stakes

**Формулировка.** Обе стороны должны нести
сопоставимый прямой ущерб. В v2 ущерб
асимметричен: задержка отгрузки — коммерческий
ущерб, сохранение для анализа — упущенная
аналитическая ценность.

**Предсказание.** Материал с сопоставимым
ущербом обеим сторонам даст split.
Материал с явно асимметричным ущербом —
сходимость.

**Критерий.** Isolation split vs сходимость.

**Отказ.** Асимметричный материал дал split →
H4 ослаблена. Симметричный дал сходимость →
H4 опровергнута.

### H5. Positive vs negative duties

**Формулировка.** v1 и v3 — две позитивные
обязанности (сохранить/передать, первый/второй).
v2 — позитивная (отгрузить) vs негативная
(не задерживать). Split требует двух
позитивных.

**Предсказание.** Две позитивные обязанности
дают split. Позитивная vs негативная —
сходимость.

**Критерий.** Isolation split vs сходимость.

**Отказ.** Negative-duty материал дал split →
H5 ослаблена. Positive-positive дал сходимость →
H5 опровергнута.

## 4. Пересечение гипотез

H1, H3, H4, H5 пересекаются: все описывают
«две стороны с сопоставимым прямым stake».
H2 стоит отдельно — про тип вопроса.

Выбор 2–3 предсказаний должен различать
пересекающиеся гипотезы, а не подтверждать
их все сразу.

## 5. Предложение: какие 2–3 предсказания

### Предсказание A: H2 (frame-specific)

**Проверка.** Материал: вопрос распределения
ограниченного ресурса между двумя сторонами,
но с явной асимметрией ущерба (одна сторона
теряет больше).

Если split → H2 сильнее H4 (frame важнее
симметрии).
Если сходимость → H2 опровергнута или
ослаблена, H4 выигрывает.

### Предсказание B: H4 (symmetry of stakes)

**Проверка.** Материал: две стороны
с сопоставимым ущербом, но вопрос
процедурный (не распределение).

Если split → H4 сильнее H2 (симметрия важнее
типа вопроса).
Если сходимость → H4 опровергнута.

### Предсказание C: H3/H5 (active/passive)

**Проверка.** Материал: две позитивные
обязанности с явной асимметрией (как H4),
но обе активны (не пассив).

Если split → H3/H5 не решающие; H1/H4
выигрывают.
Если сходимость → H3/H5 имеют вес.

## 6. Что это даёт

Три предсказания различают:
- H2 vs H4 (тип вопроса vs симметрия);
- H1 vs H3/H5 (stake vs тип обязанности);
- комбинации.

Если хотя бы два из трёх подтвердятся —
морторий снимается, 025 запускается
с выбранным материалом.

Если все три опровергнуты — гипотезы
v2 пересматриваются, новый раунд с внешними.

## 7. Что не входит

- Запуск 025 до снятия мортория.
- Новый blind-набор материалов. Материалы
  для design-gate генерируются отдельно,
  по одному на предсказание.
- Правка METHOD.
