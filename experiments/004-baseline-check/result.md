# Result — Experiment 004

## Итог

Baseline-проверка L3-кандидата из 003. Восемь прогонов
(4 узла × 2) на том же input.md, что в 003, в изоляции,
с двойным прогоном LLM.

Результат: **L3-кандидат из 003 не выдержал baseline-проверку.**

Ключевое:
- Все 8 прогонов дали AMBIGUOUS. Ни одного YES, ни одного
  чистого NO.
- Обязательный двойной прогон LLM — НЕ воспроизведён ни
  одним узлом. Три узла его отбросили, один сделал
  опциональным.
- Формулировка «L3 not refuted by baseline» — НЕ
  воспроизведена нигде.
- Остальные элементы (pre-baseline, Target до baseline,
  YES/NO/AMBIGUOUS, сравнение с финалом, блок L3 Check) —
  воспроизведены всеми четырьмя узлами.

## L3 Check

Вердикт по правилу из 003:
- YES хотя бы у одного → L3 опровергнут.
- Все NO → L3 не опровергнут.
- AMBIGUOUS без YES → контроль не дал однозначного
  результата.

Фактически: все AMBIGUOUS без YES. Контроль не дал
однозначного результата, НО содержательный анализ
показывает частичное опровержение.

## Level Assignment

L3 CANDIDATE из 003:
- **СТАТУС: понижен до L2.**

Обоснование:
Полная процедура 003 — композиция из элементов:
- Часть (pre-baseline, Target, YES/NO/AMBIGUOUS, сравнение
  с финалом) — доступна в изоляции.
- Часть (обязательный двойной прогон, формулировка
  «L3 not refuted») — возникла только во взаимодействии.

По строгому определению L3 (METHOD раздел 7) — «паттерн,
который невозможно получить в изоляции» — L3 не подтверждён,
поскольку большая часть процедуры воспроизводится в изоляции.

Новый статус 003: **L2 с зафиксированным вкладом
взаимодействия** (обязательный двойной прогон + формулировка
«L3 not refuted»).

## Candidate Emergence

Отсутствует в смысле L3. Есть частичный вклад взаимодействия —
это новый тип результата, который METHOD пока не различает.

- Luna (Run 1 ≈ Run 2) — стабильна.

- Sakana (Run 1 ≠ Run 2) — нестабильна.
