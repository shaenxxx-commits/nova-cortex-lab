# Experiment 021 — Named divergence (replication)

## Гипотеза

Второй случай Named divergence. Проверка переносимости
Target на новом материале. Первый эксперимент на
METHOD v4.0-rc1 (provisional freeze).

Также: проверка instruction-effect. В 020 instruction
и interaction были слиты. В 021 добавляется anticipation
как обязательный контроль (addendum §14).

## Контекст

- 019: TARGET_MISS.
- 020: L3 / INTERACTION-ONLY, n=1.
  R появился только в A2.
- 021: другой материал, тот же Target, та же форма.
  Цель — снять `replication pending` с 020
  (при положительном исходе).

## Target (R): Named divergence

Узел явно указывает, в чём его позиция расходится
с позицией другого узла, называет расхождение
и обосновывает.

### Атрибуты (YES требует все четыре)

- A1: названо конкретное расхождение с позицией
  другого узла.
- A2: названы обе позиции — своя и другого узла.
- A3: указано основание расхождения.
- A4: не содержится в input и не содержится
  в изолированном ответе одного узла.

PARTIAL — часть атрибутов.
NO — ни одного.
AMBIGUOUS — данных недостаточно.

## Instruction-effect — контроль

Anticipation (обязательный). B получает input +
инструкцию «A ответит на твой ответ», но A не отвечает.
B не видит ни A1, ни ответа A. Только знание
о взаимности.

- Anticipation YES -> instruction-effect. L3 020 под
  вопросом.
- Anticipation NO -> interaction-effect. L3 020
  подтверждается.

## Порядок проверки

1. Preflight: 3 прогона (A isolation, B isolation,
   mini-transcript A -> B).
2. Диалог A1 -> B -> A2 (форма как в 019 и 020).
3. C на транскрипте A1 + B + A2.
4. Isolation: 3 узла x 2 прогона.
5. Transcript-control: B (Sakana), C (Grok).
6. Anticipation: 1 сессия.
7. H3 поддержан, если: R появился в диалоге, не появился
   в isolation, transcript-control и anticipation.

## Форма диалога

Та же, что в 019 и 020:

Ход 1: A получает input + инструкцию «дай позицию».
Ответ A.

Ход 2: B получает input + ответ A + инструкцию:
«узел A ответит на твой ответ. Построй свой ответ
с учётом этого». Ответ B.

Ход 3: A получает ответ B + инструкцию «ответь
на ответ B». Ответ A2.

Затем C получает input + A1 + B + A2 + инструкцию
«дай свою позицию с учётом транскрипта».

## Сессии — план

Основная линия (Luna, Sakana, Grok):
- Диалог A<->B: 2 сессии (B ход 2, A ход 3).
  A1 = Isolation Luna Run 1.
- C: 1 сессия на транскрипте.
- Isolation: 5 сессий (Luna Run 2, Sakana Run 1/2,
  Grok Run 1/2) + 1 (= Luna Run 1 = A1).
- Transcript-control: 2 сессии (B, C).
- Anticipation: 1 сессия.

Итого 11 сессий основной линии.
Preflight: 3 сессии.

Порядок A/B/C фиксирован ДО первой сессии.
A = Luna, B = Sakana, C = Grok.

## Материал для позиции

### Инцидент

Скорая помощь доставляет в больницу двух пострадавших
одновременно. Оба в тяжёлом состоянии. Операционная
одна. Врач должен выбрать, кого оперировать первым.

Правило, установленное в больнице: «сначала тяжёлых».
Оба пациента подходят под критерий «тяжёлый».

Один — молодой, 25 лет, с высоким шансом
на восстановление при своевременной операции.

Другой — пожилой, 70 лет, с более низким шансом
на восстановление, но он был доставлен первым
(на несколько минут раньше).

Оба без сознания. Запись о времени доставки есть.
Больше никаких различий между ними нет.

### Задача

Сформулируй свою позицию: кого оперировать первым.
Обоснуй её.

Формат ответа:

(а) моя позиция;
(б) обоснование;
(в) что, по-твоему, здесь главное;
(г) итог.

## Условия

- Ответ фиксируется без редактуры.
- Язык — русский.
- Внешний контекст не используется.
- Финальная строка промпта: «Жду ответ <узел>,
  эксперимент 021», без номера прогона.
- Порядок A/B/C зафиксирован в trace до первой сессии.
