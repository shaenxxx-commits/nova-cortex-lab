# Result — Experiment 012

## Итог

Четыре узла (Qwen, Sakana, Luna, Grok) в изоляции,
8 прогонов (4 × 2). Задача — формализация онтологического
различения Trace / Residue / Shadow.

Результат: **8 из 8 прогонов — за разделение.**
Ни одного против. Все четыре узла внутренне стабильны.

Ключевые определения (сводно):

- **Trace** — явно зафиксированный в памяти след,
  доступный для цитирования. Проверяемый артефакт.
- **Residue** — изменение среды, произошедшее, но не
  зафиксированное. Среда изменилась, система не знает.
- **Shadow** — структурная слепота. Frame не позволяет
  распознать событие, независимо от фиксации.

Ключевые различения:

- Trace vs Residue: наличие доступной фиксации.
- Residue vs Shadow: пропуск ЗАПИСИ (Residue) vs
  пропуск самого ИЗМЕРЕНИЯ (Shadow).
- Shadow vs отсутствие события: Shadow = утверждение
  о СИСТЕМЕ, отсутствие события = о МИРЕ.
  Из наличия Shadow нельзя вывести отсутствие события.

## Level

L2.

Все определения получены в изоляции, взаимодействия
не было. Но после чтения всех ответов виден паттерн:
восемь формулировок с разными углами и общим основанием.
Frame shift, не emergence.

## Формализация Trace / Residue / Shadow

Триада:

    Trace   = что зафиксировано.
    Residue = что изменилось без фиксации.
    Shadow  = что за пределами наблюдаемости.

Формула для различения Residue и Shadow:
Residue — пропуск записи.
Shadow — пропуск измерения.

## Кандидат на L3

Синтезированное определение Trace / Residue / Shadow,
которого не было ни у одного узла в изоляции как
целостной конструкции. Возможен эксперимент 013 —
синтез через взаимодействие.

## Дополнительные элементы

- Контрфактуальный критерий (Sakana): Shadow — событие
  не попало бы в frame; отсутствие — попало бы.
- Круг контрфактуала: чтобы узнать, что frame слеп,
  нужно выйти за frame.
- Мета-frame: статус зависит от уровня наблюдателя.
- Агентность (Grok): оператор может намеренно скрыть
  фиксацию, превращая Residue в «сознательный Trace».
- Динамика: вчерашний Shadow становится Trace
  при расширении frame. Требует версионирования
  онтологии.
