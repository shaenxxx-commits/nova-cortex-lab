# Experiment 019 — Interaction

## Input

input.md. Материал: четыре определения «надёжность источника»
(юридическое, научное, журналистское, сетевое). Автор — оператор.
Задача: критика в формате (а)-(г).
Форма: диалог A↔B (3 хода) + C на транскрипте + isolation
+ transcript-control + subset.
Ручная передача. Один оператор. Инкогнито-сессии.

## Задача 019

Первый спроектированный тест H3 (interaction contribution).
Валидация meta/method-interaction-addendum.md одновременно
с проверкой гипотезы Interaction > Node.

## Target (Interaction-Target)

Явное правило приоритета R между конфликтующими определениями:
при каких условиях какое определение берёт верх.

### Критические атрибуты

- A1: R — операциональное правило переключения
  («при X → [i], при Y → [j]»). Не «зависит от контекста»,
  не сортировка «A > B > C > D».
- A2: обоснование.
- A3: хотя бы одно явное условие «когда R не применять».
- A4: SYNTHETIC — объединение ≥2 определений,
  не прямое следствие одного.

Уровень A4 (EXPLICIT / DERIVABLE / SYNTHETIC)
фиксируется отдельно. Принято только SYNTHETIC.

## Место первого появления R (3a)

Заполняется по ходу. Одно из:

- A1 — R в первом ходе A. Не H3.
- B — R в ответе Sakana. Возможно H3, зависит от isolation.
- A2 — R во втором ходе A (ответ на B). Сильный H3-сигнал.
- C — R только у Grok на транскрипте. НЕ H3 без фиксации
  R в A1/B/A2.
