## Target (Interaction-Target)

Явное правило приоритета R между конфликтующими определениями:
при каких условиях какое определение берёт верх.

R формулируется ДО эксперимента. В ответе узла появляется
в разделе (в) или (г).

### Критические атрибуты (для шкалы 5.2)

YES требует все четыре:
- A1: R явно сформулировано как правило;
- A2: R имеет обоснование (почему именно так);
- A3: R указывает границы применимости (когда не работает);
- A4: R не содержится ни в одном из четырёх исходных
  определений.

PARTIAL — присутствует часть атрибутов.
NO — ни одного.
AMBIGUOUS — данных недостаточно.

## Порядок проверки (по addendum §3)

1. Формулировка Target (сделано выше).
2. Лестница A→B→C. A получает только input, B — ответ A,
   C — ответ B (кумулятивный контекст).
3. Фиксация: появилось ли R в финальном артефакте.
4. Isolation baselines (H1): 3 узла x 2 прогона = 6 чистых
   сессий на исходном input.
5. Transcript-control (ключевая проверка H3): узел B
   получает транскрипт ответа A без присутствия A.
   Воспроизводит ли R из одного транскрипта.
6. Subset: минимальная пара (A+B) — одна сессия.
7. Только если шаги 4 и 5 не дают YES, а шаг 2 дал R —
   H3 поддержан.

## Сессии — план

Основная линия (Luna, Sakana, Grok):
- Лестница: 3 сессии (A, B, C).
- Isolation: 3 узла x 2 прогона = 6 сессий.
- Transcript-control: 3 сессии (B видит транскрипт A;
  C видит транскрипт B; вариация — C видит транскрипты A+B).
- Subset: 1 сессия (минимальная пара).

Итого 13 сессий на основную линию.
Порядок узлов фиксируется в trace.

Confounded condition (Qwen):
- Isolation: 2 прогона.
- В лестницу не включается.
- Помечено `*`, в основную статистику не входит.

## Что измеряется

- Число YES / PARTIAL / NO / AMBIGUOUS в каждом типе прогона.
- В каком узле или паре возникло R.
- Форма R (если возникло).
- Отличие лестницы от transcript-control по появлению R.

## Ожидание

- Если R появляется в лестнице и не появляется в isolation
  и transcript-control — H3 поддержан.
- Если R появляется в isolation — не H3, H1 YES.
- Если R появляется в transcript-control, но не в isolation —
  content-effect, не H3.
- Если R нигде не появляется — Target не достигнут,
  результат NO.

Отклонения — тоже данные.
