# PARTICIPANTS

Узлы, участвующие в экспериментах. Не рейтинг. Наблюдения.

Формат обновляется по мере накопления наблюдений.
Записи не удаляются, только дополняются.

## Люди

### Оператор

- Роль: оператор, узел
- Вход: с 2026-09-24
- Работает в паре с LLM-ассистентом (DeepSeek). Ассистент —
  часть роли оператора, не самостоятельный узел.
- Заметки:
  - ведёт эксперимент вручную, переносит сообщения между узлами
  - фиксирует свои действия в trace.md
  - не прозрачный посредник — участник

## Формат записи

Для каждой модели фиксируется:

- дата входа
- наблюдения (сильные / слабые стороны)
- заметки по ходу работы

Оценки не выставляются. Рейтинги не ведутся.
Записи обновляются, а не переписываются.
